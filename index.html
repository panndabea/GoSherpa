Warum GoSherpa

Wenn der Code zum Gebirge wird, zeigt GoSherpa die Route.

GoSherpa liest dein Go-Projekt strukturell statt magisch. Die CLI gibt dir ruhige, wiederholbare Antworten, die du im Terminal scannen, in Reviews verwenden oder als kompakten Kontext an Coding Agents weitergeben kannst.

  • Wo ist das definiert? Symbol, Datei, Signatur und Zeilennummer.
  • Wer benutzt das? Referenzen, direkte Caller und relevante Tests.
  • Was ruft diese Funktion auf? Callees und lokale Call-Pfade durch dein Repository.
  • Was betrifft mein Diff? Betroffene Packages, Risiko und sinnvolle Testbefehle.

Symbole finden

Vom Namen zur Definition: GoSherpa zeigt dir Signatur, Package, Datei, Dokumentation und passende Treffer, ohne dass du das Projekt durchklicken musst.

gosherpa symbol ParseFile

Impact einschätzen

Ein kleiner Change kann mehrere Routen berühren. GoSherpa zeigt betroffene Packages, geänderte Symbole, Risiko und die Tests, die jetzt wirklich zählen.

gosherpa impact diff --base HEAD

Kontext weitergeben

Für Menschen lesbar, für Tools stabil: Kontextbefehle exportieren Source-Auszüge, Beziehungen, Tests, Grenzen und JSON in einer kompakten Form.

gosherpa context symbol ParseFile --json

Was die Software kann

Konkrete Antworten statt Code-Nebel.

GoSherpa ist bewusst als CLI gebaut: kleine Befehle, stabile Ausgaben, menschenlesbar zuerst und mit JSON, wenn Automatisierung gebraucht wird.

Symbolatlas Listet Structs, Interfaces, Funktionen und Methoden im Projekt. gosherpa symbols
Suche & Referenzen Findet partial Matches und Go-bewusste Referenzen, optional nach Art gefiltert. gosherpa refs ParseFile --kind call
Call-Beziehungen Zeigt direkte Caller, Callees und kurze lokale Pfade zwischen Funktionen. gosherpa path Run ParseFile
Abhängigkeiten Macht Package-Imports, lokale Dependents und Interface-Implementierungen sichtbar. gosherpa deps ./internal/sherpa
PR-Intelligenz Fasst Diffs zusammen und nennt Risiko, betroffene Bereiche und Verifikation. gosherpa pr --base HEAD
Agent-Kontext Exportiert begrenzte, deterministische Kontextpakete für Codex, Claude Code, Cursor und CI. gosherpa context diff --json

Für Menschen und Agents

Ein gemeinsamer Blick auf dieselbe Repository-Intelligenz.

GoSherpa versucht nicht, dein IDE zu ersetzen. Es macht die Struktur deiner Codebasis sichtbar, damit du beim Lesen, Ändern und Reviewen weniger raten musst.

Entwickler

Schneller verstehen, wo etwas lebt, wer es benutzt und wie groß der nächste Schritt wirklich ist.

Review

PR-Zusammenfassungen, betroffene Tests und Risiko-Hinweise direkt aus dem Diff.

Automation

Stabile JSON-Umschläge für Scripts, CI und Coding Agents, die keinen Projektroman brauchen.

# Ein Symbol verstehen
gosherpa explain ParseFile

# Betroffene Tests fuer ein Diff
gosherpa tests affected --base HEAD

# Kompakter Agent-Kontext
gosherpa context package ./internal/sherpa --json

Ausprobieren

Starte lokal in wenigen Befehlen.

GoSherpa ist ein frühes MVP, aber die Grundroute steht: bauen, testen, fragen, verstehen. Für GitHub Pages ist diese Seite als statische Root-Page vorbereitet.

Repository öffnen README ansehen 
git clone https://github.com/panndabea/GoSherpa.git
cd GoSherpa
go test ./...
go build -o gosherpa ./cmd/gosherpa

./gosherpa doctor
./gosherpa symbols
./gosherpa impact diff --base HEAD
