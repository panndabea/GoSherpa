Warum GoSherpa

Wenn der Code zum Gebirge wird, zeigt GoSherpa die Route.

GoSherpa liest dein Go-Projekt strukturell statt magisch. Die CLI gibt dir ruhige, wiederholbare Antworten, die du im Terminal scannen, in Reviews verwenden oder als kompakten Kontext an Coding Agents weitergeben kannst.

  • Wo ist das definiert? Symbol, Datei, Signatur und Zeilennummer.
  • Wer benutzt das? Referenzen, direkte Caller und relevante Tests.
  • Was ruft diese Funktion auf? Callees und lokale Call-Pfade durch dein Repository.
  • Was betrifft mein Diff? Betroffene Packages, Risiko und sinnvolle Testbefehle.

Sofort ausprobieren

Ein kleiner Install-Flow, dann echte Repository-Antworten.

GoSherpa soll sich wie ein normales Go-Tool anfühlen: lokal installieren, Readiness prüfen, Projekt verstehen und den nächsten Review- oder Agent-Schritt mit Kontext füttern.

Wofür du es nutzt

GoSherpa beantwortet Arbeitsfragen, nicht nur Feature-Listen.

Die besten Einstiege sind konkrete Situationen: Review, Onboarding, Symbolarbeit und Agent-Kontext.

Einen PR reviewen

Fasse den Diff zusammen, lies Risiko und leite Verifikation direkt aus betroffenen Packages ab.

gosherpa pr --base main

RISK medium
AFFECTED ./internal/sherpa
VERIFY go test ./internal/sherpa
In ein Go-Repo einsteigen

Starte mit Architektur, Hotspots und Symbolinventar, ohne dich erst durch alle Ordner zu klicken.

gosherpa analyze .
gosherpa architecture
gosherpa risk
Ein Symbol ändern

Finde Definition, Referenzen, Caller, Callees, relevante Tests und eine sinnvolle Lesereihenfolge.

gosherpa explain ParseFile
gosherpa refs ParseFile --kind call
gosherpa tests ParseFile
Einem Agent Kontext geben

Gib Codex, Claude Code oder Cursor begrenzten JSON-Kontext statt ein ganzes Repository in den Prompt zu kippen.

gosherpa context diff --base HEAD \
  --max-files 20 --max-symbols 40 \
  --max-tests 20 --max-bytes 12000 \
  --json

Agentische Workflows

Agent Guide lesen

Agent Guide

Ein klarer Startpunkt für Coding Agents.

Die Kurzfassung: erst Readiness prüfen, dann begrenzten Kontext holen, Impact verstehen und Tests planen, bevor ein Agent Code ändert.

Vollständigen Guide auf GitHub lesen
  1. Readiness prüfen Go-Umgebung, Modul, Snapshot und Analyse-Vertrauen vor der Arbeit sichtbar machen. gosherpa doctor --json
  2. Kontext begrenzen Nur die Dateien, Symbole, Tests und Quell-Auszüge laden, die für den aktuellen Diff zählen. gosherpa context diff --base HEAD --max-files 20 --max-symbols 40 --max-tests 20 --max-bytes 12000 --json
  3. Impact lesen Betroffene Packages, geänderte Symbole und mögliche Caller-Ketten prüfen. gosherpa impact diff --base HEAD --json
  4. Tests planen Sinnvolle Testbefehle aus dem Diff ableiten, statt blind alles oder gar nichts zu starten. gosherpa tests affected --base HEAD --json

Copy-Paste-Startpaket für Agents

Diese Sequenz reicht für viele Review-, Repair- und Edit-Aufgaben: erst Vertrauen prüfen, dann nur begrenzten Diff-Kontext laden.

gosherpa doctor --json
gosherpa context diff --base HEAD --max-files 20 --max-symbols 40 --max-tests 20 --max-bytes 12000 --json
gosherpa impact diff --base HEAD --json

Was die Software kann

Konkrete Antworten statt Code-Nebel.

GoSherpa ist bewusst als CLI gebaut: kleine Befehle, stabile Ausgaben, menschenlesbar zuerst und mit JSON, wenn Automatisierung gebraucht wird.

Symbolatlas Listet und filtert Structs, Interfaces, Funktionen und Methoden im Projekt. gosherpa symbols --kind function
Suche & Referenzen Findet partial Matches und Go-bewusste Referenzen, optional nach Art gefiltert. gosherpa refs ParseFile --kind call
Call-Beziehungen Zeigt direkte Caller, Callees und kurze lokale Pfade zwischen Funktionen. gosherpa path Run ParseFile
Interfaces & Verträge Zeigt Methoden, Implementer, Typ-Referenzen und sichtbare Interface-Methodennutzung. gosherpa interface UserRepository
PR-Intelligenz Fasst Diffs zusammen und nennt Risiko, betroffene Bereiche und Verifikation. gosherpa pr --base HEAD
Agent-Kontext Exportiert deterministische Kontextpakete mit Limits für Codex, Claude Code, Cursor und CI. gosherpa context diff --base HEAD --max-files 20 --json
